Este repositório contém a API desenvolvida por **Dário Quental** para o Projeto Final, integrando serviços REST, resiliência com Polly, cache local e autenticação JWT.

- **Backend**: .NET 8 (ASP.NET Core Web API)
- **Segurança**: Autenticação e Autorização via JWT (Bearer Token)
- **Resiliência e Cache**: Polly (Retry, Circuit Breaker) e Memory Cache
- **Mock Externo**: Ficheiro Mountebank (`mountebank.json`) para simulação de inventário
